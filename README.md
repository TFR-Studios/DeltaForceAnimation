# 三角洲行动动画编辑器(Bodymovin / Lottie JSON)

针对《三角洲行动》撤离/位置暴露动画(After Effects + Bodymovin 导出 JSON)的网页编辑器,支持文字/颜色编辑、实时预览,以及带背景颜色的视频导出。

**内置两套独立动画**,顶栏「动画」下拉框可随时切换编辑:

- **撤离动画**(`animation/animation_data.json` + `animation/ccreptile` 序列图 + `animation/gunmuchenggong.mp3`):含弹窗叠加层(`windows_animation.json`),侧栏「弹窗图层」可编辑;
- **位置暴露动画**(`animation_2/animation_data.json` + `animation_2/UI_C201_Energy_Scout_Bow_Scout_02.wav`):无弹窗,切换后「弹窗图层」面板自动隐藏;其内嵌音频为 Bodymovin 导出的坏占位符,已剥离,运行时注入独立的 WAV 音效(预览与导出均含该音效)。
  - 该动画的「底框」图层在 AE 中是轨道蒙版源(`td:1`,仅作为百叶窗.png 的 alpha 蒙版,lottie 中不渲染)。为还原 AE 中「既作蒙版又显示」的效果,已在 JSON 中新增一份可见副本图层「底框(可见)」(去掉 `td`,其余属性与原层一致),原蒙版层保留不动。若重新用 AE 导出,需重新添加该副本。
  - **二次扫描底框修复**:合并二次扫描时会对第二段所有形状路径执行「手柄绝对化」转换(复刻 lottie 的 `convertPathsToAbsoluteValues`)。原因:Bodymovin 导出的路径手柄是相对值(如 `[0,0]`),lottie 加载时会在 `completeData` 中就地转为绝对坐标并打 `__complete` 标记;而合并数据深拷贝了已加载的主动画(带 `__complete`),再加载时 lottie 跳过转换,第二段竖条等形状的相对手柄 `(0,0)` 被当作绝对控制点,渲染成向形状原点弯曲的弧线(竖条斜向屏幕下方)。若日后重新导出第二段 JSON,此修复依然有效。
  - **二次扫描装饰图层**:合并时保留「百叶窗2.png」(金色编织纹理)与「光.png」(光带),并用 lottie 的 `tp` 字段显式指定轨道蒙版源(百叶窗2 → 底框,光.png → 形状图层 4),解决 lottie 默认按数组相邻配对导致蒙版失效、纹理全屏平铺的问题;
  - **二次扫描底框与主段一致**:合并时统一第二段底框(可见)**所有形状组填充为 #000000**(第二段 AE 导出时竖条填充为绿色,侧栏形状图层显示的正是该填充,故侧栏/渲染均不显示黑色;统一后侧栏显示 #000000、竖条为金色描边+黑填充,与第一段"红描边+黑填充"结构一致),黑矩形不透明度 55%;底框宽度自适应文字、图标随文字左缘自适应、矩形不透明度滑块均对两段生效(第二段底框默认 X 缩放基准 160.164%,适配 8 字「即将扫描移动单位」);
  - **图标**:二次扫描默认图标与主段一致(均为 Hero_Sp_03.png),切换图标时两段同步更新;侧栏「显示图标」开关可隐藏两段图标,取消后文字回到画面中心(p.x=960)且主段底框/竖条整组同步左移(底框中心与文字中心重合,左右留白对称),恢复后还原;图标选择区另有「居中微调 ◀ ▶」按钮,可在隐藏图标状态下对文字(及跟随底框)做 ±8px 手动微调,用于抵消不同字体/文字内容的字形光学偏差(重置归零);图标隐藏通过透明度动画关键帧置 0 实现(lottie 对静态 ks.o=0 不生效);
  - **二次扫描默认时长 2.7s**(总播放 = 主段 + 2.7s + 5 帧缓冲),可在侧栏「二次扫描时长」滑块调整。
  - **文字宽度适配的字距修正**:文字宽度测量(底框/图标自适应、弹窗宽度自适应)按 lottie 渲染公式计入字距 `tr`(`tr×0.001×字号` 每字母),此前仅测字形宽导致计算偏小,文字变长后底框/图标位移不足、间距拉大;图标位置改为始终跟随文字左缘(变长左移、变短右移),底框缩放保持"超过 4 字且变宽才放大"的规则。
  - **图片纹理调色/透明度(两段)**:侧栏「图片图层」面板支持主段「百叶窗.png」(默认红 #e23b3b)、二次扫描段「百叶窗2.png」(默认金 #ffca5e)与「光.png」(默认金 #ffca5e)各自调色(保留原图亮度、替换色相/饱和度)与图层不透明度调整;开/关二次扫描时面板自动刷新,重置恢复原始颜色与透明度。默认透明度:光 70%、百叶窗2 100%(淡入淡出保留);**调色时若纹理透明度低于 100%,颜色会被透明度压暗而几乎不可见,会自动把该图层透明度提升到 100% 使所选颜色立即可见**(可再手动调整滑块)。

**`animation_data.json` 已打包进网站**,打开页面即可直接编辑该动画,无需服务器接口。音频使用 `animation/` 目录下的 `gunmuchenggong.mp3`(同样打包进网站),不再使用 JSON 内嵌音频。

**弹窗动画 `animation/windows animation/windows_animation.json` 也已打包进网站**(与主动画同为 1920×1080@60fps):可在侧栏「弹窗图层」中勾选「显示弹窗」控制是否叠加显示,弹窗与主动画按帧号同步(播放/暂停/拖动时间轴/切换渲染器均跟随)。

## 运行

```bash
npm install
npm run dev
```

然后打开 http://localhost:5173

- 页面启动后自动载入打包的 `animation_data.json`;
- 预览支持:播放/暂停(空格键)、重播、循环、速度 0.1–3 倍、SVG/Canvas 渲染器切换、背景色/透明、适配方式(包含/铺满/原始);
- 编辑支持:文字图层的内容与颜色、形状图层的填充/描边颜色,均可实时修改并一键重置;
- 弹窗(windows_animation)支持:
  - 「显示弹窗」复选框控制弹窗叠加层显隐(**默认关闭**,勾选后显示),与主动画同帧号同步;
  - 弹窗文字图层:可改文字内容、颜色、对齐方式(左/居中/右,默认居中 `j=2`,编辑文字后保持居中);
  - **弹窗宽度自适应文字宽度**:编辑弹窗文字后,底板(「弹窗用的底板」「弹窗底部」)与蒙版宽度按文字宽度增量同步伸缩,两侧留白保持不变;感叹号图标始终位于文字图层左侧并随文字左缘同步移动,重置后恢复;
  - 弹窗颜色图层:可改填充/描边颜色,**名称含「蒙版」的图层不可改色**(列表中已排除);
  - 导出视频时若开启弹窗,弹窗会自动合成到主动画之上。

## 视频导出(60fps,含音频)

导出会携带背景颜色,规则如下:

- **勾选「透明背景」** → 自动导出 **AVI**(MP4 不支持透明,此时格式选择框自动锁定为 AVI)。透明 AVI 使用**无压缩 32 位 BGRA** 编码,保留真正的 alpha 透明通道,可直接导入支持透明视频的剪辑软件(体积较大:1080p60 约 8MB/帧);
- **选择 MP4 / AVI(未勾选透明)** → 使用当前选择的**背景色**导出;两者均为 H.264 30 Mbps(1080p 清晰流畅,PotPlayer/VLC/剪映均可硬解),AVI 为 H.264-in-AVI 封装(带 avcC,FFmpeg 系播放器/剪辑软件通用)。

## 说明

- 动画数据通过 `src/main.ts` 以 `?raw` 形式打包进构建产物(`dist/`),音频文件以 `?url` 形式一并打包,发布时只需部署静态文件即可,所有人打开网页就能编辑。
- 更换动画:替换 `animation/animation_data.json`(撤离)或 `animation_2/animation_data.json`(位置暴露)后重新 `npm run build` 即可。
- 新增动画:在 `src/main.ts` 中 `import` 新的 JSON 后,往 `ANIMATIONS` 注册表添加一项(含数据/弹窗/音频),顶栏下拉框会自动出现新选项。
- 更换音频:替换 `animation/gunmuchenggong.mp3`(保持文件名),或在 `src/main.ts` 中修改音频导入。
- 字体:若 JSON 通过 `fonts.list[].fPath` 内嵌了 TTF 字体文件,编辑器会自动用 FontFace API 加载并注册,两种渲染器都会使用真实字体;未内嵌字体的动画则回退到系统字体。
- Canvas 渲染器:本动画的 JSON 只有内嵌字体文件、没有字形轮廓数据(`chars`),lottie-web 原生 Canvas 渲染会因此崩溃。编辑器内置了兼容层:自动预加载字体 + 原生 `fillText` 文字兜底绘制(保留逐字母动画)。

## 其他命令

- `npm run build` — 类型检查 + 产物构建(`dist/`)
- `npm run preview` — 本地预览构建产物(动画数据已打包,与线上一致)

## 部署到 Cloudflare Pages

1. 将本仓库导入 Cloudflare Pages(或连接 GitHub 自动构建);
2. 构建设置:
   - **构建命令**:`npm run build`
   - **输出目录**:`dist`
   - **Node.js 版本**:22(仓库内已提供 `.nvmrc`)
3. 部署后打开站点即可编辑与导出,无需任何后端服务。
